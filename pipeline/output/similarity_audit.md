# 유사도 신뢰성 측정

`python -m pipeline.run --steps audit`로 다시 만듭니다. 연구실 479곳, 유사도 선 1249개, 모델 `sentence-transformers/allenai-specter`.

> **사람이 평가한 정답과 비교한 결과가 아닙니다.** 아래는 안정성과, 다른 신호와의 일치 정도만 보여 줍니다.

## 숫자의 의미

- 모든 연구실 쌍의 유사도 중앙값은 0.7307입니다. 선을 긋는 기준 0.9174는 전체 쌍의 상위 2.3%입니다. 0.92가 "92% 비슷하다"는 뜻은 아닙니다.
- 입력: 연구실당 논문 중앙값 17편, 하위 10%는 6편 이하. 초록이 있는 논문 82%, 나머지는 제목만 씁니다.

## 3. 다른 신호와 일치하는가

- **공동연구**: 공동 논문을 양쪽 벡터에서 뺀 뒤 계산해도 공동연구 쌍 659개의 유사도는 전체 쌍의 96번째 백분위(중앙값)입니다. 같은 대학·같은 분야 쌍은 84번째입니다. 공동연구는 원래 가까운 사람끼리 하므로 정확도 자체를 뜻하지는 않습니다.
- **OpenAlex 주제**: 상위 15개 주제의 자카드 지수가 이웃은 0.158, 무작위 쌍은 0.012입니다. 이웃의 8%는 공통 주제가 없습니다.
- **같은 분야 비율(상위 5개)**: chem 82%, cs 93%, life 89%, math 82%, phys 81%

## 4. 설계에 따른 변화와 쏠림

- 인용 가중치를 빼면 상위 5개 이웃의 83%가 유지됩니다.
- 가장 많이 이웃으로 뽑힌 연구실은 26곳의 이웃이고, 35곳은 누구의 상위 5개에도 없습니다. 논문 수(로그)와의 상관은 0.35입니다.
- 공통 OpenAlex 주제가 없는 유사도 선은 9개입니다.

## 사이트에 반영한 내용

- 소수점 값 대신 구간으로 표시합니다. 분야마다 값의 범위가 달라 구간 경계도 분야별로 정합니다.
- 논문이 10편 이하인 연구실의 이웃에는 달라질 수 있다는 안내를 붙입니다.
- 선을 클릭하면 벡터가 가장 가까운 논문 쌍을 보여 줍니다. 사용자가 제목으로 직접 판단할 수 있게 하기 위해서입니다.
